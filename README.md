## Description
This project is a simple grade calculator created using HTML, CSS, and JavaScript. It calculates a student's grade based on marks entered out of 100.

## Features
- Accepts marks from the user.
- Uses if-else conditional statements.
- Displays grades from A+ to F.
- Validates marks between 0 and 100.
- Includes a simple and responsive design.

## Technologies Used
- HTML
- CSS
- JavaScript

## Grade Criteria
- 90–100: A+
- 80–89: A
- 70–79: B
- 60–69: C
- 40–59: D
- Below 40: F (Fail)

## How to Run
1. Open assignment16.html in a web browser.
2. Enter marks between 0 and 100.
3. Click the Calculate Grade button.
4. View the result.
